## [section_1] Return states

A return moves through: requested, label issued, in transit, received, closed.
Only *received* and *closed* mean the goods are physically with Voltline. A
return in any earlier state has not arrived, whatever the courier's tracking
page shows.

## [section_2] Inspection outcomes

Inspection records one of: pending, passed, failed. Inspection normally
completes within 2 working days of the return being received. A *pending*
inspection is a wait, and the customer should be told the return has arrived
and inspection is in progress.

## [section_3] Failed inspection

Where inspection fails -- for example the item is missing accessories, shows
use beyond inspection tolerance, or does not match the returned line item --
the case must be referred to a support reviewer with the inspection notes. An
agent must not refuse the refund outright and must not issue it.

## [section_4] Returns not on record

If the customer says they returned an item but no return exists against the
order, the agent should explain that no return has been registered and offer to
start one. This is a missing-information case, not a refusal.
